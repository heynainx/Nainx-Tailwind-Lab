# Nainx-Tailwind-Lab
NainX Tailwind Lab

A premium Tailwind CSS lab from zero to pro for modern UI builders

Live Demo
Find live demo on Vercel search nainx tailwind lab

About This Project
This lab contains more than five hundred Tailwind CSS components from basic to pro level
You can learn practice copy and use in real projects

Features

More than five hundred Tailwind CSS components with explanation and preview
Buttons cards navbars hero sections grids flex layouts forms tables modals animations glassmorphism neumorphism dashboards
Live preview with instant render and copy code button
Responsive design that works on mobile tablet and desktop
Dark and light mode support
Search any component fast with command palette
Clean and modern UI with reusable classes
Quizzes with instant result and explanation
Certificate generator with QR code and verifier page
Full auth system with full name username email password and repassword

Tech Stack

Frontend HTML plus Tailwind CSS plus JavaScript plus Framer Motion
Code Viewer Prism JS
Icons Lucide plus Heroicons
Backend Supabase for favorites and progress

Setup Locally

First clone the repo
Second open folder in VS Code
Third run with live server or npm run dev if using Vite
